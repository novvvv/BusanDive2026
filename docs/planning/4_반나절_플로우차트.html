FLOW 01

관광지 추천 — 역방향 필터

관광지를 먼저 고르고 짐을 나중에 걱정하는 대신, 짐 맡길 수 있는 곳만 후보로 삼습니다.

"마지막 날 어디가 좋아?"
취향 · 시간 · 지역 조건이 섞인 열린 질문
의도 파악 → 관광지 추천 도구 호출
조건을 파라미터로 변환 (지역 · 테마 · 소요시간)
도구 진입 — 이하 전부 규칙 기반
① 보관함 보유 역 집합 확정
71개 역 중 특대형 보유 역만 남김
② POI 후보 조회
부산테마여행 API + 반나절 적합성 큐레이션 태그
③ 좌표 거리 계산
POI 위경도 × 역사 정보 114역 위경도
도보 접근 가능 거리 내
④ 교집합만 남김
보관함 보유 역 인근 POI = 추천 후보
결과 조합 → 사용자 언어로 답변
관광지 설명은 API 공식 번역문 인용, 연결 문장만 생성
관광지 3~5곳 제시
각 후보에 인근 역 · 도보 시간 · 해당 역 특대형 칸수 병기
부산테마여행 API 역사 정보 114역 물품보관함 71개 역 큐레이션 태그
이 순서가 핵심입니다. ①에서 보관함 보유 역을 먼저 확정하기 때문에, "추천했는데 근처에 짐 맡길 데가 없다"는 실패가 구조적으로 발생하지 않습니다.
FLOW 02

짐 보관 옵션 — 픽업과 보관함 병렬 조회

두 수단을 동시에 조회해 후보로 나란히 놓고, 사용자가 근거를 보고 고릅니다.

"남포동 갈 건데 캐리어는 어떡하지?"

권역별 운영 규칙 테이블

보관소 조회
선택 관광지 인근 역의 보관함 조회
특대형 칸수 · 거리순 정렬
상위 1~3개로 제한
두 결과를 하나의 답변으로 조합
픽업 가능 시 함께 제시, 불가 시 보관함만 제시
보관 옵션 카드 제시
위치 · 보유 칸수 · 요금 · 상세위치({층, 출입구} 파싱)
픽업 가능 숙소 목록 물품보관함 71개 역 운영 규칙 테이블
