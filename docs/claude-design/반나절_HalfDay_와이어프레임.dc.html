1반나절 · 화면 흐름 (서비스 이용 순서)

화면과 설명을 실제 이용 흐름 순으로 정렬했어요 — 왼→오로 읽으면 사용자 여정이 됩니다. 채팅이 골격이라 STEP 4~5는 대화 중 카드에서 파생되는 오버레이, 6~7은 같은 정보를 페이지로도 보는 병렬 탭이에요. 각 카드의 STEP n 배지가 순서, 회색 블록 = 컴포넌트 자리, 오른쪽 주석은 결정·비타협 원칙(§7) 위치예요.
