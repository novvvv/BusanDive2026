# 요약

언어 전환(ko/ja/en) 시 한국어로 남아 있던 영역을 전면 다국어화하고, 채팅·픽업 탭 UI를 재구성했다.
보관함 위치 문구와 지하철 역명은 규칙 기반 변환·공식 데이터 매칭으로, 짐캐리 FAQ·등록 숙소 342곳의
숙소명·주소는 번역 맵과 도로명주소 로마자 변환기로 처리해 세 언어 모두 일관된 화면을 제공한다.
채팅에서는 다시하기 칩을 제거하고 스크롤 시 진입 퀵바를 노출한다.

## 변경 사항

### 다국어화

- **보관함 위치 문구** (`lib/subwayLockerLoc.ts` 신규): `loc` 정형 문구(출입구·개찰구·고객센터 등)를
  규칙 기반으로 ja/en 변환. 보관소 목록·상세 시트·채팅 카드 3곳 적용. 미등록 문구는 원문 유지.
- **지하철 역명 매칭 보정** (`lib/subwayNames.ts`): 정규화에 괄호 병기 제거(`하단(부산본병원)`→`하단`) +
  접두 일치 폴백(`국제금융센터`↔`국제금융센터.부산은행`) 추가 — 외국어 표기가 안 나오던 25개 역 해소.
  ko 표시는 입력 역명 기준 유지.
- **짐캐리 FAQ** (`lib/zimcarryFaq.ts` 신규): 10개 문항을 3섹션(예약·변경·취소 / 짐 맡기기·받기 /
  파손·분실 보상)으로 구조화하고 전 문항 ja/en 번역 + 가독성 줄바꿈. `content.ts`의 `ZC.faq`는 제거(이전).
- **등록 숙소 342곳** (`lib/zimcarryHotelNames.ts` 신규): 숙소명 ja/en 표기 맵(전수 커버 검증) +
  도로명주소 로마자 변환기(연음·자음동화·번길/번가길 처리, 영문 주소 형식 재배열). ja는 예약 플랫폼
  관례대로 로마자 주소 사용.

### 채팅 (`ChatScreen.tsx`, `types.ts`)

- "↻ 다시 하기" 칩 제거 (`ChipVM.variant`도 정리, 언어 전환용 `reset()`은 유지).
- 진입 칩 2종(숙소 픽업 / 여행지 근처 보관함)을 `entryChips`로 공용화 — 스트림을 아래로 스크롤하는
  제스처에서만 입력바 위 왼쪽 퀵바로 노출, 위로 스크롤·프로그래매틱 이동 시 숨김.

### 픽업 탭 (`pickup/page.tsx`, `Icons.tsx`)

- 이용 방법 4단계를 2×2 그리드에서 세로 리스트로 전환.
- 예약 CTA: 카드 래퍼 제거·크기 축소(44px), "짐캐리 공식 사이트로 이동 · 당일 온라인 예약 11:00까지"
  캡션 추가(마감 시각은 정책 데이터 참조).
- 무인 보관함: 타이틀에서 "· 부산" 분리 → 지역 뱃지로, 크기별 요금을 셀 그리드(흰 카드 래핑)로 교체.
- 등록 숙소: 숙소명 옆 `StayIcon` 추가, "등록" 뱃지 제거.
- FAQ 아코디언 +/− 를 `ChevronDownIcon` 회전으로 교체.

### 설정

- `next.config.mjs`: `NEXT_DIST_DIR` 환경변수로 distDir 지정 지원 — 검증 빌드가 dev 서버 `.next`를
  오염시키지 않도록 분리.
